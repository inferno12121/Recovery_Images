This repository contains **custom recovery images** created for **OPLUS Pineapple series devices**.

You can download the recovery images from the **Releases** section and install them using the following commands:

```bash
fastboot flash recovery_a recovery.img
fastboot flash recovery_b recovery.img
```

## Supported devices

| Device | Regions / Variants |
|------|--------------------|
| OnePlus Ace 5 / OnePlus 13R | CN, GL, IN |
| OnePlus Ace 3 Pro | CN |
| OnePlus Ace 3 V / OnePlus Nord 4 | CN, GL, IN |
| OnePlus 12 | Global |
| Realme GT 6 | CN |
| OPPO Find X7 Ultra / Satellite | Global |
